# Screenshots

This directory contains screenshots captured during the OWASP Juice Shop Web Application Security Assessment using Burp Suite Professional. The screenshots are organized to demonstrate the complete assessment workflow, including environment setup, application mapping, request and response analysis, and manual security testing.
